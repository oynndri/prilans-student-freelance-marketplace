# Prilans — Student Freelance Marketplace

Prilans is a student-focused freelance marketplace connecting university students with clients. Built with Vue 3, Vite, and Tailwind CSS, featuring project discovery, search and filters, student profiles, project applications, and skill-based matching.

## 🚀 Tech Stack
- **Framework**: Vue 3 (Composition API & `<script setup>`)
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide (`lucide-vue-next`)

## 🛠️ Getting Started

### Installation
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## ✨ Key Features
- **Accurate Dashboard Interface**: Faithful implementation of the Prilans marketplace reference design.
- **Real-Time Search & Clear**: Filter by titles, descriptions, skills, and client locations.
- **Multi-Faceted Filtering**: Filter by category, experience levels, budget brackets, proposal counts, and project type (Hourly vs. Fixed Price).
- **Sorting & View Switching**: Sort by newest, oldest, or budget, and toggle between two-column grid and list views.
- **Application Workflow**: Interactive "Apply Now" with applied state management.
- **Fully Responsive**: Mobile menu drawer, collapsible filter panels, and responsive grid layouts.
